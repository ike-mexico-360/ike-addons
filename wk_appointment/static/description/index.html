Essential Features of Our Module

We are excited to introduce the latest features that will enhance your user experience!

Arrange Meetings and Appointments

  • Helps you arrange meetings and book appointments for your clients easily.
  • Users can book an appointment for a customer with a selected appointee 
  • Admin can create and assign timeslots for each day like Monday, Tuesday, etc.

Define Time Slots for Appointments

  • Odoo Appointment Management System provides a date and time slot to a customer when booking an appointment.
  • Admins can now create timeslots from the “Appointment Time Slots” menu without selecting the day each time. 
  • Day selection is only required when assigning a timeslot to an appointee.

Enhanced Calendar View

  • Filtered appointments in the calendar for the selected appointee
  • Dynamic appointment count cards based on the currently selected appointee.
  • Book Appointment button now available directly in the Calendar view.

Dashboard and Analytics

  • Track appointment status
  • Filter earnings by time intervals: Current Week, Month, or Last Year.
  • View the number of appointments based on their status: New, Cancelled, Pending, or Done
  • Separate charts display appointments by their status. Users can switch between charts for earnings and appointment states.
  • Note: Earnings are based on paid invoices. Mark the invoice as paid to reflect in the charts.

Appointment Charges

  • Set unique charges for each appointee.
  • Customers are charged according to the chosen appointee.
  • A user can add the lines in Appointment to apply Charges and taxes in the booked appointment.

Approve or Reject Appointments

  • Approve or reject appointments directly from the appointment form.
  • Maintain appointment status for every action taken.

Prerequisites for Using the Module

For Odoo Online (SaaS) users, you must first set up Odoo.sh before installing Appointment Management System, as Odoo Online (SaaS) restricts the installation of third-party modules.
